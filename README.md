# ClearVid

本地 AI 视频修复工具：硬字幕/水印去除 + 老片修复。所有处理在本机 GPU 完成，文件不出本地。

> ⚠️ 本工具仅供合法用途：处理您拥有权利的视频素材（自己拍摄的内容、获授权的素材、公版老片等）。请勿用于去除他人版权内容的保护措施或任何侵犯版权的行为。

## 功能路线

- [ ] 视频硬字幕自动检测与擦除（CLI）
- [ ] 水印/台标区域选区擦除
- [ ] 老片修复：去噪 / 去划痕 / 超分
- [ ] GUI 与批量处理
- [ ] 高质量修复引擎（ProPainter）
