# ClearVid 项目计划书

## 一、定位

**ClearVid**：本地化 AI 视频修复工具，主打两个合规场景：

1. **硬字幕 / 水印去除**：自媒体剪辑、课程切片、素材二次创作的刚需
2. **老片修复**：划痕、噪点、低分辨率修复增强，面向档案馆、家庭录像、影视爱好者

**不做**：人脸马赛克重建、规避版权保护技术措施的用途。README 明确合法用途声明。

## 二、商业模式（参照 Jasna 验证过的模式）

| 层级 | 内容 | 价格 |
|---|---|---|
| 免费版 | E2FGVI 快速修复、CLI + 基础 GUI、720p 上限 | 免费（GitHub 引流） |
| 支持者版 | ProPainter 高质量修复、4K、批量、老片修复管线 | ¥68-98 买断 |
| 专业版 | 扩散模型级修复（自研微调）、优先支持、商用授权 | ¥299 / 年 |

- 收款渠道：爱发电 / Buy Me a Coffee / 闲鱼（国内主力）
- 开源协议：AGPL-3.0（防白嫖商用）+ 付费内容闭源分发（许可证码激活）

## 三、技术架构

```
输入视频 → FFmpeg/NVDEC 解码
        → 字幕/水印检测（CRAFT / PaddleOCR 定位文字 + 时序跟踪）
        → mask 生成（膨胀 + 时序平滑）
        → 修复引擎（免费: E2FGVI / 付费: ProPainter / 自研扩散）
        → 只重绘 mask 区域，其余像素原样保留
        → NVENC 编码 + 音频直通 → 输出
老片管线：去噪(Real-ESRGAN 系) → 去划痕 → 超分 → 可选上色(DeOldify)
```

## 四、里程碑

### M1（第 1-2 周）：市场验证 —— 不写代码先赚钱
- 用现成工具（ProPainter 官方 repo + 手动 mask）人工跑几单
- 在闲鱼/淘宝挂"视频去字幕/水印代处理"服务，验证付费意愿和客单价
- 产出：真实订单数据、定价依据

### M2（第 3-6 周）：MVP
- CLI 工具：输入视频 + 自动字幕检测 + E2FGVI 修复 + 输出
- 自动 mask：PaddleOCR 定位字幕区域 → 时序合并（同一区域连续帧合并为 clip）
- 硬件底线：GTX 1660 / 6GB 显存可跑
- 产出：v0.1 GitHub 发布 + B 站/小红书演示视频引流

### M3（第 7-10 周）：产品化
- Gradio/PySide6 GUI：选区预览、批量队列、实时进度
- ProPainter 高质量引擎接入（付费版）
- Windows 一键安装包（嵌入 Python + 模型，规避环境地狱）
- 产出：v0.5 + 付费版上架

### M4（第 11-16 周）：老片修复管线 + 护城河
- 老片管线：去噪 → 去划痕 → 超分 整合为一键流程
- 评估自研微调：基于 LTX-Video / CogVideoX 做字幕擦除微调（此时用前期收入覆盖算力成本）
- 产出：v1.0 + 专业版
