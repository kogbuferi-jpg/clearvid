# 闲鱼市场验证操作手册（M1）

目标：**零开发成本验证付费意愿**。用现成开源工具人工跑单，看有没有人愿意付钱。

## 一、卖什么

| 服务 | 定价建议 | 说明 |
|---|---|---|
| 视频去硬字幕 | ¥5-15 / 条（≤1分钟） | 走量款，测试转化率 |
| 视频去水印/台标 | ¥10-20 / 条 | 需要手动框选，报价略高 |
| 长视频（课程/影视切片） | ¥30-80 / 条（≤10分钟） | 按时长阶梯报价 |
| 老录像修复（超分+去噪） | ¥50-150 / 条 | 高客单价测试 |

测试技巧：同一条服务挂两个链接，不同价格，看哪个转化好（A/B 测试）。

**正文**：

**配图**：左原图右修复图的对比截图（效果对比是最强转化器）。

## 三、接单工作流

1. 客户发视频 → 你用 ClearVid/ProPainter 跑前 3 秒出试看片段
2. 发试看 → 客户确认付款（闲鱼担保交易，别走微信直转）
3. 跑完整视频 → 网盘发货 → 客户确认收货

**防坑**：
- 一定"先试看后付款"，避免跑完单客户说不要了
- 交付前视频打水印预览，付款后给无水印版
- 明拒单：盗版电影整片、明显侵权内容，直接不接（话术："版权素材处理不了哈"）

## 四、验证标准（跑 2 周）

| 结果 | 结论 |
|---|---|
| 2 周内 ≥10 单，或 ≥3 个复购/批量客户 | 需求验证通过，全力投入 M2 开发 |
| 有咨询但嫌贵/嫌慢 | 调整定价或主打速度，再试 1 周 |
| 几乎无人咨询 | 换场景（试老片修复单）或放弃，损失=两周时间 |

## 五、客户画像记录

每单记下：客户是干什么的（自媒体/教培/电商？）、素材类型、愿意付多少钱、抱怨什么。
这些数据直接决定 v0.1 先做哪个功能。
